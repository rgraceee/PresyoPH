# Brand artwork

`logo.png` and `sidebar_illustration.png` were exported from the Figma file (nodes 5:688 and 5:749) at 1x and
had the sidebar's green background removed. For sharper artwork on high-density screens, export the same two
nodes from Figma as SVG and save them here (app/ui/assets/) as `logo.svg` and `sidebar_illustration.svg`; `shell.py` prefers
the SVG files when they exist.
