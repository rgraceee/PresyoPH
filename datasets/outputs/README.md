# Forecasting outputs

Generated by `modeling/run_pipeline.py` (task 5). Do not edit these files by
hand; re-run the pipeline instead:

```
.venv/Scripts/python -m modeling.run_pipeline
```

Only national all-items CPI is modeled. Inflation and purchasing power are
derived from each CPI forecast with PSA's formulas, so every model has values
for all three variables. ETS is not in the proposal and is included for
comparison only.

Dates are the first day of the month (`YYYY-MM-DD`). Variables are `cpi`
(index, 2018 = 100), `inflation` (year-on-year, percent), and
`purchasing_power` (pesos, 2018 = 1.00 peso).

## forecasts.csv

The forward-looking forecasts shown on the dashboard. Every model is refit on
all data up to the last released month and forecasts the next 12 months.

| Column | Description |
|---|---|
| origin | Last month of data used (the forecast starts the month after) |
| model | ARIMA, Linear Regression, Moving Average, or ETS |
| variable | cpi, inflation, or purchasing_power |
| date | Forecast month |
| step | Months ahead (1–12); the dashboard's 3- and 6-month views are steps 1–3 and 1–6 |
| forecast | Forecast value |
| lower, upper | 95% prediction interval |
| is_selected | True for the final model chosen in task 4 |

## test_predictions.csv

Forecasts made during evaluation, with the published actual values. Used for
actual-vs-forecast charts.

| Column | Description |
|---|---|
| evaluation | `main_test` (origin Aug 2025) or `rolling_origin` (five earlier origins) |
| origin, model, variable, date, step, forecast, lower, upper | As in forecasts.csv |
| actual | PSA's published value for that month |
| error | actual − forecast (positive = forecast too low) |

## metrics.csv

MAE, RMSE, and MAPE for every model and variable. MAE and RMSE are in the
variable's own units; MAPE is in percent.

| Column | Description |
|---|---|
| evaluation | `pooled` (all six origins, used for selection), `main_test`, `rolling_fold`, or `rolling_average` |
| period | Which period or fold the row covers |
| model, variable | As above |
| mae, rmse, mape | Error metrics |
| n_months | Number of forecast months scored |
| is_selected_model | True for the final model |
| used_for_selection | True for the rows the selection rule was applied to |

## error_by_step.csv

Mean absolute error at each step ahead, pooled over all six evaluation origins.
Shows how forecast reliability falls as the horizon grows.

| Column | Description |
|---|---|
| variable, model | As above |
| step | Months ahead (1–12) |
| mae | Mean absolute error at that step |

## model_info.json

The final model, the selection rule and its result, the data period, and the
fitted settings of every model at the final origin.

## Notes for users of these files

- **Intervals for inflation and purchasing power** are converted from the CPI
  interval. Both formulas move in one direction with CPI, so the conversion is
  exact.
- **Moving Average intervals can lie entirely above its forecast** at longer
  steps. Its intervals are built from its own past errors, and because CPI has
  always risen, a flat forecast has historically been too low by six or more
  months ahead. This reflects the method's bias and is expected.
- **Inflation MAPE is large and unstable**, because actual inflation was as low
  as 0.9–1.5% in some months. Read it alongside MAE and RMSE.
- The selection basis was changed from the main test alone to the pooled six
  origins after the results were seen. See `notebooks/03_evaluation.ipynb`.
